# MãoCerta MZ

MVP mobile-first para ligar clientes a prestadores de serviços em Moçambique.

## Testar

Abra `index.html` no navegador ou publique estes ficheiros num alojamento estático (GitHub Pages, Netlify ou Vercel). Não precisa de servidor para testar.

## O que já funciona

- pesquisa por texto, categoria e cidade;
- perfis de prestadores;
- ligação direta ao WhatsApp;
- cadastro de novos prestadores guardado no navegador;
- interface responsiva para telemóvel;
- instalação como PWA quando servido por HTTPS.

## Próximos requisitos para negócio real

A versão atual é um MVP: os cadastros ficam apenas no navegador de cada utilizador. Para operar publicamente, ligue um backend (por exemplo Supabase), autenticação de administrador, moderação, domínio, analytics e um método de pagamento compatível com Moçambique. Não foram incluídas cobranças automáticas porque exigem conta, credenciais e validação legal do proprietário.
